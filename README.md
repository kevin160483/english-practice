# 英文口說練習站

上完課把講義和錄音丟進 `inbox`，雙擊一個檔案，網站就多一課：
老師念的每一句被切成獨立音檔，可以逐句跟讀、錄自己的版本、A/B 對照，
並依間隔複習跨課排出每天該練什麼。電腦和手機都能練。

**講義和上課錄音永遠留在你電腦上。** 上傳到網路的只有切好的單句小音檔，
而且全部加密過，沒有密碼的人只會看到亂碼。

---

## 第一次：跑一次「install.bat」

1. 把整個資料夾放到好找的位置，例如 `C:\英文課\`
2. 雙擊 **`install.bat`**

它會自己做完這些事，你只要在幾個地方輸入或按確認：

| 它會做什麼 | 你要做什麼 |
|---|---|
| 裝 Python、ffmpeg、Git、GitHub CLI | 等（可能跳出安裝視窗，讓它跑完） |
| 下載語音辨識與範讀語音模型 | 等（約 200MB） |
| 問你要設什麼密碼 | 輸入一個長密碼，存進密碼管理器 |
| 打開瀏覽器請你登入 GitHub | 登入，選項都按 Enter |
| 建立網站、給你網址 | — |
| 問你手機推播的名稱 | 填 ntfy 的主題名稱，或按 Enter 略過 |

跑完最後會顯示你的網址，也會寫在 `site-url.txt` 裡。

> **密碼很重要**：忘記就打不開舊課程。建議四個英文單字組起來，例如
> `copper-lantern-drift-84`。網站雖然是公開網址，但資料是用這個密碼加密的
> （PBKDF2 25 萬次 + AES-256-GCM），密碼強度就是你的保護。

> 中途出錯的話，把紅字訊息複製給 Claude。安裝可以重複執行，它會從沒做完的地方繼續。

## 每週：兩個動作

1. 把講義和上課錄音放進 `inbox` 資料夾，**檔名配成一對**：

   ```
   inbox\L3.docx     講義
   inbox\L3.mp4      上課錄音（.m4a .mp3 .mp4 都可以）
   ```

2. 雙擊 **`add-lesson.bat`**

錄音太大會先自動壓縮（只取聲音），然後辨識、切句、補範讀、加密、上傳。
一小時的錄音大約 20–40 分鐘，中間不用管它，跑完視窗會顯示網址。

處理完原始檔案會移到 `inbox\done`，留在你電腦上。

**只有講義、還沒有錄音也可以**：範讀會先用合成語音。之後補上錄音，
把講義和錄音一起放進 inbox 再跑一次，老師原聲會覆蓋掉合成的。

## 怎麼練

打開 `site-url.txt` 裡的網址（電腦、手機都用同一個），輸入密碼，勾「記住這台裝置」。

**今日** 是跨課的。第三週開始，今天的隊列會混進第一、二課的句子 ——
那是刻意的，隔一段時間再想起來才是真的記住。

練習畫面的循環：

1. **聽範讀** — 有 ♪ 老師原聲標記的就是老師的聲音
2. 切到 **0.75×** 跟著念一次（老師的聲音放慢音高不會跑掉，重音特別清楚）
3. **錄音** — 用正常速度念自己的版本
4. **A/B 對照** — 連續播老師和你，差最多的通常是字尾子音和重音位置
5. 評 **再練一次 / 還行 / 很好** — 下次複習時間自動排（1、2、4、7、14、30、60 天）

念不順的按 **☆ 標記難句**，之後可以只練標記的。
鍵盤：空白鍵錄音／停止，`1` 聽範讀，`2` 我的錄音，`3` A/B，`→` 下一題。

**你自己的錄音和練習進度存在當下那台裝置的瀏覽器裡**，不會上傳。
換手機用「音檔 → 匯出進度」搬過去。

**沒網路想練**：雙擊 `practice-offline.bat`，會在電腦上開同一個練習站。

## 東西都存在哪裡

| 資料 | 位置 | 誰看得到 |
|---|---|---|
| 講義原檔、上課錄音 | `inbox\done`（你的電腦） | 只有你 |
| 切好的老師音檔、講義文字 | 網站上，加密 | 有密碼的人 |
| 你自己的錄音 | 瀏覽器內部儲存 | 只有那台裝置 |
| 練習進度 | 瀏覽器內部儲存 | 只有那台裝置 |
| 密碼 | `password.txt`（你的電腦） | 只有你 |

`inbox` 和 `password.txt` 都設定成不會上傳（見 `.gitignore`）。

## 想調整的時候

| 想改什麼 | 怎麼改 |
|---|---|
| 換合成語音 | `scripts\tts_fallback.py` 最上面的 `VOICE`：`en_US-ryan-high`（男）、`en_US-hfc_female-medium`（女）、`en_US-lessac-high`、`en_US-amy-medium` |
| 辨識更準（更慢） | `scripts\align_audio.py` 的 `MODEL` 改 `medium.en`；想快用 `base.en` |
| 對齊太鬆／太嚴 | 同一支檔案的 `ACCEPT`（預設 0.62，越高越嚴） |
| 複習間隔 | `docs\app.js` 的 `STEPS` |
| 提醒時間 | `.github\workflows\remind.yml` 的 cron（UTC，台北時間減 8 小時） |

## 出問題時

**網站說「密碼不對」** — `password.txt` 的內容跟建立那些課時用的不一樣。

**老師原聲很少** — 錄音裡老師念得不完整，或雜訊太大。把 `MODEL` 改成 `medium.en`
再跑一次同一課。網站的「音檔」分頁會顯示每一句的相似度，可以拿來判斷。

**上傳失敗** — GitHub 登入過期。開命令提示字元打 `gh auth login` 重新登入，
或直接再跑一次 `add-lesson.bat`。

**處理中斷** — inbox 裡的檔案還在，修好後再跑一次就好，已經做完的課不會重做。

**手機不能錄音** — 確認網址是 `https://` 開頭，第一次會跳權限請求。

## 檔案結構

```
install.bat            第一次跑一次
add-lesson.bat       每週雙擊
practice-offline.bat         沒網路時在電腦上開練習站
site-url.txt            你的練習站網址
password.txt            加密用的密碼（不上傳）
inbox\              放講義與錄音（不上傳）
docs\               網站本體 + 加密後的課程資料（這個會上傳）
scripts\
  setup.ps1         安裝流程
  run.ps1           每週的處理流程
  parse_docx.py     講義 → 結構化資料
  align_audio.py    Whisper 辨識 + 模糊比對 + 切句
  tts_fallback.py   Piper 合成老師沒念到的句子
  pack.py           加密
  build_lesson.py   一堂課的完整流程
  process_inbox.py  掃 inbox 並逐課處理
```
